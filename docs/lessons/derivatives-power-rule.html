    2.3 幂法则的几何来源

    找出新增面积或体积的一阶部分，并说明哪些角落在差商极限中消失。

    例题练习Lean 对照原课

    一步一步建立直观

    先预测，再点“演示本步”核对右图。每一步都重设到指定情形，随后可以自由修改参数。

    01把立方体的变化拆成薄层

    切换到立方函数，把边长 aa 增加 hh。三个面旁各添一层厚度 hh 的薄片，主项合计为 3a2h3a^2h；棱边附近的重叠修正含 h2h^2，角上的小块含 h3h^3。体积图像解释了为什么系数是三，而不是一个需要记住的巧合。

    02先除以步长，再比较阶数

    对立方函数，差商是 3a2+3ah+h23a^2+3ah+h^2。右图可先切回平方函数，比较其中只有一个一阶误差项的情形。两者都不是把高阶项直接删掉，而是在除以 hh 之后，证明剩余误差随 hh 趋零。然后再推广到整数次幂。

    03把局部近似与大步长分开

    将步长调大，割线明显偏离切线。幂法则给出的是观察点附近的一阶倍率，不能用它精确预测任意远处的变化。对于一般实数指数，还需要说明函数定义域；本窗口的平方、立方只是几何推导最直接的两个例子。

    2.3.1 为什么平方会带出一个二¶

    边长为 xx 的正方形，每边增加 hh，新增区域由两条宽为 hh 的长条和一个小角组成。两条长条总面积为 2xh2xh，小角为 h2h^2。除以边长增量 hh 后，长条贡献 2x2x，小角只贡献 hh，趋零时消失。

    这解释了二次幂导数中的系数二来自两条边，不是套公式的巧合。立方体则有三个主要薄层，每层体积约为 x2hx^2h；交叠边角含更多个 hh，在除以 hh 后仍趋零，所以得到 3x23x^2。

    2.3.2 从图形推广到代数¶

    更高次幂不容易画，但展开乘积 (x+h)n(x+h)^n 时可以数贡献。一阶项必须从 nn 个因子中恰好选一个 hh，其余选 xx，一共有 nn 种选法，所以系数是 nxn−1nx^{n-1}。选两个及以上 hh 的项都带 h2h^2 或更高次。

    “高阶项小”必须说明与什么相比。导数计算比较的是它们相对于 hh 的大小，而非只看绝对值。如果一个误差恰为 3h3h，它虽然趋零，除以 hh 后仍留下 33，不能丢掉。

    把 x=2,h=0.1x=2,h=0.1 代入立方增量，先算精确值，再算 3x2h3x^2h 的预测，最后减出误差。这个小实验会把导数理解为有误差控制需求的局部预测器。自然数幂的规则可以统一证明，非整数幂则要重新核对定义域。

    与本图相连的定义与证明：2.2 · 平方函数的差商与误差。本节的具体条件与形式化范围见下文。

    数学表述 2.3.1¶

    边长增加 hh 时，正方形多出两条窄带和一个小角；小角面积是二阶量。立方体的第一阶体积变化来自三个面。

    对自然数 nn， (x+h)n=xn+nxn−1h+O(h2),(xn)′=nxn−1.(x+h)^n=x^n+nx^{n-1}h+O(h^2),\qquad (x^n)'=nx^{n-1}. 这里的余项表述对固定 xx、有限多项式成立。实数非整数幂需要额外的定义域条件。

    例 2.3.1 把概念用于具体计算

    x3x^3 的变化为 3x2h+3xh2+h33x^2h+3xh^2+h^3。差商去极限得到 3x23x^2，在 x=2x=2 处为 1212。

    辨析 2.3.1

    “高阶项很小”必须相对于 hh 比较；常数 n=0n=0 的导数为零。

    练习 2.3.1¶

    求 f(x)=5x4−2x2+7f(x)=5x^4-2x^2+7 的导数。

    展开解答与检查

    答案 20x3−4x20x^3-4x。

    Lean 对照 2.3.1 命题、证明与适用边界

    完整调用并验证自然数幂的一般导数定理；Lean 中自然数的 n−1n-1 是截断减法，n=0n=0 由前面的零系数正确处理。

    HasDerivAt (fun t : ℝ => t^n) ((n:ℝ)*x^(n-1)) x := hasDerivAt_pow n x
