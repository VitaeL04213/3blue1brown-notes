洛必达法则：比较消失速度

先识别未定式，再追踪分子分母的消失速度，记录适用条件。

两个量都趋零，比例仍可能完全不同

x/xx/x、x2/xx^2/x 与 x/x2x/x^2 的分子分母都趋零，比值却分别趋向一、零，或在零附近无界。零除以零不是一种答案，它只是提示直接代入没有揭示相对消失速度。需要进一步比较两个量的一阶或更高阶变化。

若 f(a)=g(a)=0f(a)=g(a)=0，且两者可导、g′(a)≠0g'(a)\ne0，局部近似给出 f(a+h)≈f′(a)hf(a+h)\approx f'(a)h 与 g(a+h)≈g′(a)hg(a+h)\approx g'(a)h，因此比例接近导数之比。这个简单版本提供了直觉，但一般洛必达法则可以处理更复杂的去心区间情况，需要明确的条件。

法则是有条件的工具

下面列出的条件要求相关区间可微、分母导数不为零，并且导数比值具有极限。使用时先判断原式的未定形式，再核对这些条件。仅仅看到一个分式，不意味着可以把分子分母各求一次导数。

例如 (x+1)/(x+2)(x+1)/(x+2) 在零附近没有未定性，直接连续代入得 1/21/2；随意求导反而得到一。又如 (x2−1)/(x−1)(x^2-1)/(x-1) 在一处，可以因式分解直接求极限，没必要把简单结构藏到一般定理里。

如果一次求导后仍是未定式，再用一次也要重新核对条件。洛必达法则的假设不满足，并不能反推原极限不存在，只能说明这个工具暂时不给结论。解题时应先看能否约分、换元或利用已知局部近似，再考虑更一般的方法。

要点回看

当分子分母同时趋零时，比值取决于它们接近零的速度。导数可揭示这个速度，但需要足够的可微性条件。

数学表述

一个常用 0/00/0 版本要求：f,gf,g 在去心区间可微，g′≠0g'\ne0，f,g→0f,g\to0，且 f′/g′→Lf'/g'\to L；在相应单侧区间条件下可推出 f/g→Lf/g\to L。双侧结论须两侧一致。

完整算例

limx→1(x2−1)/(x−1)=2\lim_{x\to1}(x^2-1)/(x-1)=2。可以用导数比值 2x/12x/1，也可以先因式分解，后者在此更直接。

检查误区

原比值不是未定式时不能随便求导。例如 (x+1)/(x+2)(x+1)/(x+2) 在零点的极限为 1/21/2，导数比值却为 11。

自测与答案

求 limx→0(ex−1)/x\lim_{x\to0}(\mathrm{e}^x-1)/x。答案 11，由指数函数在零点的导数定义即可得到。

Lean 证明与边界

完整验证上述有理函数的去心极限，方法是局部化简与连续性；没有把它标成一般洛必达法则的形式化证明。
