    2.9 把任意精度写清楚

    先指定输出误差，再寻找统一有效的输入范围；不能只验证几个样本。

    例题练习Lean 对照原课

    一步一步建立直观

    先预测，再点“演示本步”核对右图。每一步都重设到指定情形，随后可以自由修改参数。

    01先由读者提出允许误差

    设你希望平方函数在 aa 处的差商距离 2a2a 不超过某个容差。先确定这个输出要求，再决定步长要缩到多小。极限定义中精度与邻域的先后次序，表达的正是“无论要求多严格，我都能给出足够近的范围”。

    02把图形的窄带翻译成不等式

    在本例中误差等于 |h||h|，因此可取与容差一样小的步长阈值。并非所有函数都如此简单：有时要先限制在一个较小邻域，再估计函数值的上界。证明的任务是找到能保证整段邻域都合格的条件，而非只试出几个漂亮样本。

    03即使切线水平，量词仍然相同

    把观察点移到零，目标斜率也变成零。此时仍需对所有足够小的非零步长给出控制，不能因为曲线在屏幕上显得平坦就结束论证。有限像素可能把小误差隐藏起来，严格定义则要求我们继续缩小任意指定的误差。

    2.9.1 把“再近一点”改成一场有规则的挑战¶

    对方先指定输出误差 ε>0\varepsilon>0，你必须给出一个输入范围 δ>0\delta>0，保证之后任何落在范围内的输入都满足要求。关键是顺序：不能先挑一个有利的输入，再为它选择范围；也不能只展示几个成功的输入。

    在线性函数 f(x)=3x+2f(x)=3x+2 中，输出误差恰为输入误差的三倍。要把输出误差压到 ε\varepsilon 以下，取 δ=ε/3\delta=\varepsilon/3 即可。这个选择展示了完整逻辑：从目标精度反推输入限制，然后对所有满足限制的输入验证。

    2.9.2 非线性时先给变化倍率一个上界¶

    平方函数的误差是 |x2−a2|=|x−a||x+a||x^2-a^2|=|x-a||x+a|。第二个因子也随输入变化，不能当常数。先要求 |x−a|<1|x-a|<1，就有 |x+a|<2|a|+1|x+a|<2|a|+1；再取 δ=min(1,ε2|a|+1),\delta=\min\!\left(1,\frac{\varepsilon}{2|a|+1}\right), 两个要求就同时成立。这个额外的一并不是答案本身，而是先把局部倍率圈住的工具。

    你可以选择更小的 δ\delta，定义不要求最佳范围。证明的目标是给出有效保证，而非求最大容许误差。这样的自由度常让推导简洁许多。

    画一条包住目标值的水平细带，再找围绕输入点的竖直细带，使图像在竖带内都落进横带。图形解释了量词，但最终仍需不等式把所有点一起控制。这是从视觉直觉走向严格论证的一次完整练习。

    与本图相连的定义与证明：2.2 · 平方函数的差商与误差。本节的具体条件与形式化范围见下文。

    数学表述 2.9.1¶

    对方先指定输出容忍误差 ε\varepsilon，我们再给输入误差上限 δ\delta。顺序不能反过来，也不能让 δ\delta 随后来选择的 xx 改变。

    ∀ε>0∃δ>0∀x,0<|x−a|<δ⇒|f(x)−L|<ε.\forall\varepsilon>0\ \exists\delta>0\ \forall x, \quad 0<|x-a|<\delta\Rightarrow |f(x)-L|<\varepsilon.

    例 2.9.1 把概念用于具体计算

    对 f(x)=3x+2,L=3a+2f(x)=3x+2,L=3a+2，选择 δ=ε/3\delta=\varepsilon/3，因为输出误差恰为 3|x−a|3|x-a|。

    辨析 2.9.1

    证明极限不能只代几个小步长。对于平方函数，|x2−a2|=|x−a||x+a||x^2-a^2|=|x-a||x+a| 还需要控制第二个因子。

    练习 2.9.1¶

    若 f(x)=5x−1f(x)=5x-1，可取怎样的 δ\delta？

    展开解答与检查

    取 ε/5\varepsilon/5 即可。

    Lean 对照 2.9.1 命题、证明与适用边界

    显式构造并验证斜率 33 的函数的 ε\varepsilon–δ\delta 证明；该结论允许 x=ax=a，比去心版本更强。

    Calculus.epsilon_delta_linear

    theorem epsilon_delta_linear (a ε : ℝ) (hε : 0 < ε) :
    ∃ δ : ℝ, 0 < δ ∧ ∀ x : ℝ, |x-a| < δ → |(3*x+2)-(3*a+2)| < ε := by
  refine ⟨ε/3, by positivity, ?_⟩
  intro x hx
  have heq : (3*x+2)-(3*a+2)=3*(x-a) := by ring
  rw [heq, abs_mul, abs_of_pos (by norm_num : (0:ℝ)<3)]
  linarith

-- A concrete removable-singularity limit, not the full general l'Hopital theorem.
