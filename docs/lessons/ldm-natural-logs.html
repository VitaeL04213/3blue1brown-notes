    5.8 自然对数为何自然

    比较相同绝对增长与相同比例增长，用倒数面积解释对数尺度。

    例题练习Lean 对照原课

    5.8.1 一种对相同比例变化给相同读数的刻度¶

    从一百增加到一百零一，与从一千增加到一千零一，绝对变化相同，但相对变化不同。自然对数在局部测量的是 dx/xdx/x，因此更接近按比例的变化尺度。相同百分比增幅产生相同对数增量。

    因为 ln\ln 与指数互逆，对 elnx=x\mathrm e^{\ln x}=x 求导，得到 x(lnx)′=1x(\ln x)'=1，所以导数为 1/x1/x。定义域要求 x>0x>0，分母也说明不能在零点套用这个推导。

    5.8.2 用面积把乘法法则重新看一遍¶

    曲线 1/t1/t 从一到 xx 的有向面积等于 lnx\ln x。区间同比例缩放时，高度相应反比例变化，面积保持；这为乘法转换成加法提供了另一种几何解释。

    当 xx 从一百变为一百零一，对数增量为 ln(1.01)\ln(1.01)，一阶近似是 0.010.01。但若从一变为二，直接把对数增量当一就不准确，因为变化已不够小。局部相对变化近似不能当成全局等式。

    读对数图时也要区分“增长量下降”和“相对增长率下降”。指数曲线在对数坐标中成为直线，因为它每单位时间增加相同的对数值。这个表示很适合检查比例增长假设，但图形近似直线仍不足以证明具体机制。

    数学表述 5.8.1¶

    ln\ln 把相对变化变成加性变化：若 xx 小幅增加 dxdx，则 dlnx≈dx/xd\ln x\approx dx/x。这让相同比例的增长具有相同对数增量。

    对 x>0x>0，(lnx)′=1/x(\ln x)'=1/x，且 lnx=∫1xdt/t\ln x=\int_1^x dt/t。与 ex\mathrm{e}^x 互逆给出 ln(ex)=x\ln(\mathrm{e}^x)=x。

    例 5.8.1 把概念用于具体计算

    xx 从 100100 增为 101101，对数增量 ln1.01≈0.00995\ln1.01\approx0.00995，一阶估计为 0.010.01。

    辨析 5.8.1

    近似 ln(1+h)≈h\ln(1+h)\approx h 只适用于 hh 接近零且 1+h>01+h>0；它不是全局恒等式。

    练习 5.8.1¶

    ln(x2)\ln(x^2) 在 x>0x>0 时的导数？

    展开解答与检查

    2/x2/x；也可先写成 2lnx2\ln x。

    Lean 对照 5.8.1 命题、证明与适用边界

    完整验证正实数处的自然对数导数，写明 x>0x>0 避免除零和实定义域误解。

    Lockdown.natural_log_derivative

    theorem natural_log_derivative (x : ℝ) (hx : 0<x) :
    HasDerivAt Real.log (1/x) x := by
  simpa [one_div] using Real.hasDerivAt_log (ne_of_gt hx)
