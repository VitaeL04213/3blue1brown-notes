注意力：按上下文加权信息

分别追踪查询、键和值，观察分数如何变成每行和为一的权重。

同一个词为什么需要不同上下文表示

想象“银行”出现在取款句子与河岸翻译任务中。初始 token 表示本身不足以决定当前语境，需要从周围位置读取信息。注意力为每个位置建立一份按上下文改变的加权汇总，而不是给所有位置固定同一平均值。

查询负责提出匹配需求，键负责供匹配，值负责携带真正传递的内容。查询与键点积得到分数，再通过归一化产生权重。键与值分开，使“怎样找到信息”和“取回什么信息”能使用不同变换。

用两个值理解汇总，再放回矩阵

只有两个标量值二与十时，权重 (0.75,0.25)(0.75,0.25) 给出四；把第二权重增大，输出向十移动。非负且和为一的权重保证汇总位于两值之间。交互实验会同时展示分数、温度、权重和输出，便于区分这四个对象。

真实单头中，每个查询都对多个键计算一行分数，所以出现 QKTQK^T。除以 dk\sqrt{d_k} 是缩放分数的设计；因果掩码让当前位置不能偷看未来 token。对每行独立归一化，再乘 VV，便批量完成所有查询的汇总。

凸包解释只约束这一步的值平均，后续输出投影、多个头和残差连接都会改变最终位置。查询“寻找某类词”的比喻有助于理解可能行为，但某个训练模型究竟学了什么，仍须查看参数和实验，不能从命名直接断言。

要点回看

查询向量表达“正在寻找什么”，键向量用于匹配，值向量提供被汇总的信息。每个位置根据自身查询选择不同的权重。

数学表述

以 token 为行：Q=XWQ,K=XWK,V=XWVQ=XW_Q,K=XW_K,V=XW_V， Attention(Q,K,V)=softmaxrow(QKTdk+M)V.\operatorname{Attention}(Q,K,V)=\operatorname{softmax}_{\mathrm{row}}\!\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V. 因果掩码 MM 禁止关注未来位置。每一行的有限权重非负且和为 11。

完整算例

两个标量值 u=2,v=10u=2,v=10，权重 (0.75,0.25)(0.75,0.25) 得输出 44，位于 [2,10][2,10] 内。

检查误区

加权平均的凸包约束只适用于单头的值汇总；输出投影、多个头及残差连接之后，最终向量不必仍在原值凸包内。

自测与答案

权重 (0.2,0.8)(0.2,0.8) 时结果？8.48.4。查询与键的维数相同，值维数可以不同。
