检查网络究竟学到了什么

把对神经元的解释当成待检验假设，观察输入扰动是否支持它。

把好听的解释变成可以检验的假设

我们容易把隐藏神经元想象成边缘、笔画或概念检测器，但这种解释必须与实际参数和行为相符。先固定网络，找出什么输入能强烈激活某个单元，再查看看似相同的特征在不同背景下是否仍产生类似响应。一次漂亮的示例不足以建立稳定解释。

把输入稍微改变，观察输出怎样变，是更直接的实验。仿射层满足 Δz=WΔx\Delta z=W\Delta x：偏置在相减时消失，所以敏感性由权重和扰动方向共同决定。某方向的小变化可能被放大，另一些方向可能被忽略。

准确、稳定与可信不是同一个量

即使原图被正确分类，平移、旋转或加一点扰动后也可能变化；普通全连接层并不会自动知道这些变化应保持类别。高置信度也只是模型输出分布尖锐，并不保证它遇到的是熟悉数据，更不保证解释正确。

设计检查时可以分三步：保留独立测试样本观察泛化；做有控制的扰动检验稳定性；对置信度分组比较预测与实际频率。三步回答不同问题，不应让一个总体准确率代替所有分析。

本节的小线性算例让你能精确追踪一次扰动，但真实网络的解释还涉及非线性与数据分布。读课程中的可视化时，应同时问“这张图支持了什么结论”和“还排除了哪些替代解释”。数学公式与实验证据在这里承担不同角色。

要点回看

隐层激活不必对应人类想象的边缘或笔画。观察权重、输入扰动和分布外样本，才能检验解释是否与实际计算一致。

数学表述

对仿射层，扰动满足 Δz=WΔx\Delta z=W\Delta x；在欧氏算子范数下 ∥Δz∥≤∥W∥∥Δx∥\|\Delta z\|\le\|W\|\|\Delta x\|。这是局部敏感性分析的起点。

完整算例

z=5x+bz=5x+b，输入增加 0.020.02，激活前的数值增加 0.10.1。偏置不影响这一差值。对于像素图，平移会改变很多输入坐标，普通全连接层并不天然平移不变。

检查误区

Softmax 的最大概率高，并不保证概率校准，也不意味着输入属于训练分布。

自测与答案

为什么只检查训练集准确率不够？模型可能记忆训练样本；还需独立测试及扰动检查。
