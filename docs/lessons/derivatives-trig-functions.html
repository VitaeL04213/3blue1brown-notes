    2.4 三角函数的导数

    把圆周运动的速度投影到两个坐标轴，解释导数的正负号。

    例题练习Lean 对照原课

    2.4.1 从圆周运动读出两个变化率¶

    单位圆上的位置写成 (cosθ,sinθ)(\cos\theta,\sin\theta)。角度增加一点，点沿圆的切向移动；切向与半径垂直，相当于把位置方向转九十度，得到 (−sinθ,cosθ)(-\sin\theta,\cos\theta)。两坐标分别告诉我们横向与纵向变化速度。

    在圆最右侧，纵向高度增长最快，正弦的变化率为一；来到最上方，高度到达峰值，一阶变化率为零；再向左上方走，高度开始下降。这样先预测符号，再看公式 cosθ\cos\theta，公式就变成了运动记录。

    2.4.2 弧度不是可省略的单位约定¶

    为什么速度向量恰好有单位长度？因为单位圆上的弧度增量等于弧长增量。若用“度”作为输入，一个单位角度只走 π/180\pi/180 的弧长，导数必须多一个换算因子。导数不仅关乎函数形状，也关乎输入单位。

    几何论证背后有一个极限：小弧段与切线方向的直线段越来越接近，例如 sinh/h→1\sin h/h\to1。若用三角不等式或面积夹逼证明它，应在弧度约定下进行，不能把待证导数又拿来证明自身。

    观看复平面动画时，同时观察位置箭头与垂直的速度箭头，再把它们分别投到横纵轴。你应能从图中解释正弦导数为何是余弦、余弦导数为何带负号。之后复合角度 2x2x 的额外倍率，将由链式法则处理。

    数学表述 2.4.1¶

    单位圆上匀速运动的切向量，把位置向量旋转 90∘90^\circ。因此横坐标 cosθ\cos\theta 的速度是 −sinθ-\sin\theta，纵坐标 sinθ\sin\theta 的速度是 cosθ\cos\theta。

    (sinx)′=cosx,(cosx)′=−sinx.(\sin x)'=\cos x,\qquad (\cos x)'=-\sin x. 弧度让单位圆上的角度增量等于弧长增量，这是导数没有额外比例系数的原因。

    例 2.4.1 把概念用于具体计算

    在 x=π/3x=\pi/3 处，正弦高度为 3/2\sqrt3/2，变化率为 1/21/2。峰值 x=π/2x=\pi/2 处的变化率为零。

    辨析 2.4.1

    若输入用“度”，函数其实是 sin(πx/180)\sin(\pi x/180)，导数要乘 π/180\pi/180。

    练习 2.4.1¶

    sin(2x)\sin(2x) 的导数是什么？

    展开解答与检查

    答案 2cos(2x)2\cos(2x)，需要链式法则。

    Lean 对照 2.4.1 命题、证明与适用边界

    完整验证实正弦在任意实点的导数；采用 mathlib 的弧度三角函数。

    Calculus.sine_derivative

    theorem sine_derivative (x : ℝ) : HasDerivAt Real.sin (Real.cos x) x :=
  Real.hasDerivAt_sin x
